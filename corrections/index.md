# Correction Notice Register

Edition label: `2026-11`

This page lists the correction notices for the DisclosureWorks Sourcebook. The policy is on the
[Corrections and Removal](../corrections-removal.md) page. Removals are recorded separately on
the [Removals Log](removals-log.md) page.

## Under review

A severity-1 report that we cannot resolve within a few days gets an interim public notice here,
saying the claim is under review ([the corrections policy](../corrections-removal.md#corrections-policy) § 4).
Each entry gives the date, the edition, the affected stable IDs and a link to the notice.

None so far.

## Correction notices

Correction notices are permanent ([the corrections policy](../corrections-removal.md#corrections-policy) § 5).
Entries are listed newest first, and each gives the date, the edition, the affected stable IDs
and a link to the notice.

None so far.
